Secretary — Product Spec Board

A genius secretary you talk to. Voice-first (OpenAI Realtime, ChatGPT-voice quality), captures tasks/dates/meetings from conversation, follows up on what you owe, and keeps an AI-adaptive dashboard of your whole "adulting" life. Web first → iOS/Android later.

MVPphases 1–5 · lovable core V1phases 6–9 · the moonshot features V2later · mobile & beyond

W7 · Voice error & limit states

Every way voice can fail gets friendly copy and one clear recovery action. No dead ends, no raw errors.

Open browser settings Type instead

Lost you for a second — hold on, rejoining the call. Your conversation is safe.
End call auto-retry 2/5
⏳ Daily voice limit reached
You've used today's 30 voice sessions. Resets at midnight — typing still works.
Continue in text
🔧 Voice is taking a break
Voice is briefly down for maintenance (VOICE_DISABLED). Everything else works.
Continue in text

Procrastination score (v1 heuristic)

score = w₁·postponedCount + w₂·ignoredNudges + w₃·ageVsTypical + w₄·dueDateSlippage — recomputed nightly and on status change. Top offenders surface in briefings and the 😬 zone. Tune weights by feel; keep the function pure and unit-tested.

Suggested tasks (v1 sources)

1) Recurrence: same task title/pattern appearing at intervals (rent, invoices). 2) Prerequisites: new task/event implies others (trip → passport, insurance, transfers). 3) Seasonal/annual: things mentioned ~1yr ago (taxes, renewals). All land as source='suggested', never auto-committed; max one spoken mention per conversation.
